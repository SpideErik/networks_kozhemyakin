# Домашнее задание 10, краткая выжимка по транспортному уровню.

## TCP и UDP: надёжность, порядок и цена соединения

1. Транспортный уровень обеспечивает передачу данных между приложениями на разных устройствах и использует порты для их адресации.
2. Основные протоколы транспортного уровня — TCP (Transmission Control Protocol) и UDP (User Datagram Protocol).
3. TCP обеспечивает надёжную передачу данных: подтверждает получение, повторно отправляет потерянные сегменты и сохраняет порядок байтов.
4. TCP устанавливает соединение с помощью трёхэтапного рукопожатия (SYN, SYN-ACK, ACK) перед передачей данных.
5. TCP использует управление потоком и перегрузкой сети, но это увеличивает накладные расходы и может снижать скорость передачи.
6. UDP передаёт данные отдельными дейтаграммами без предварительного установления соединения.
7. UDP не гарантирует доставку данных и сохранение порядка сообщений, а также не выполняет повторную передачу потерянных дейтаграмм.
8. Благодаря отсутствию установки соединения и меньшим накладным расходам UDP обычно быстрее и подходит для коротких запросов, DNS, потокового видео и онлайн-игр.
9. Главное отличие: TCP выбирают, когда важны надёжность и порядок данных, а UDP — когда важны скорость и минимальные задержки.
